# 练习：开发环境

对应课程第 3 讲的练习（节选，按主题归入本 skill），复习用。

1. **配置语言服务器**。为你正在做的一个项目配置 IDE 扩展和语言服务器，确保所有预期功能都能正常工作——比如对库依赖跳转到定义。手头没有可用于练习的代码，可以从 GitHub 上找一个开源项目。
2. **装一个扩展**。浏览一份 IDE 扩展列表，安装一个看起来对你有用的扩展。
