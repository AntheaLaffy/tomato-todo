# 练习：Git 数据模型

对应课程第 5 讲的练习（节选，按主题归入本 skill），复习用。

1. **把命令对回数据模型**。如果你没有 Git 使用经验，先读 [Pro Git](https://git-scm.com/book/en/v2) 前两章，或过一遍 [Learn Git Branching](https://learngitbranching.js.org/)；过程中把每条 git 命令对应回数据模型：它往对象库里加了哪些对象？更新了哪个引用（包括 HEAD）？
