# 练习：智能体上下文管理

对应课程第 7 讲的练习（节选，按主题归入本 skill），复习用。

1. **AGENTS.md + Skill + 子智能体**。为你选择的编程智能体创建并测试一个 AGENTS.md（或等效文件，如 CLAUDE.md）、一个 Skill、一个子智能体。思考什么场景选哪个：三者都在往上下文里装东西，取舍是什么？你的智能体可能不支持其中某些功能——跳过，或换一个支持的智能体试试。
