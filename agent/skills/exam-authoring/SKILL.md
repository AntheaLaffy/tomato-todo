# 有依据的命题与组卷

目标是产出能测出指定能力、答案成立、评分可重复的题目。**真题是命题质量基准，不是唯一题源；资料多样性不能成为降低质量的理由，也不能被“只用真题最稳妥”取代。** 高水平指测量目标与任务一致、条件严谨、设问有效、有迁移价值，不等于偏、怪、计算长。

## 运行入口与按需阅读

先读 [运行入口](references/runtime.md)，确定资料权限、取材方式与保存位置。番茄 Todo 用 `read_skill(name="exam-authoring", reference="references/runtime.md")`；Codex 直接读取本技能相对路径。

- 找资料或拟定蓝图：读 [各类资料的命题价值](references/material-roles.md)。它按用途说明贡献与边界，不是资料优劣榜。
- 按科命题和复解：只读 [分科审校](references/subject-checks.md) 中对应学科。
- 组卷、审校和发布：读 [工作产物与发布检查](references/work-products.md)。少量练习可合并记录，但不能省掉逐题依据、答案与验证。

## 必须遵守的约束

1. **看过才引用。** 索引、文件名、资源登记、搜索摘要只能定位；读到有关原文才可作为本题依据。题干、条件、图表、引文、页码、题号、勘误、官方规则不得凭记忆补全。PDF同时记物理页与印刷页，识别有歧义就查看原页；仍不清楚则换用可读材料或留下精确缺口。
2. **用途决定证据要求。** 范围与正式规则须有适用版本的规范依据；知识结论须能在相关原文或可复现验证中成立；真实情境须忠于材料；学情只由实际记录支持。不能用经验帖证明官方规则，用外刊难词证明考试难度，用勾选任务证明掌握。原件自称“官方”也须核对来源。
3. **真题定质量，不包办取材。** 从同科目、同卷型且结构仍适用的真题中建立质量锚点，比较设问颗粒度、认知操作、信息负荷、条件充分性、干扰项和评分要求。频次不等于重要性或未来概率。真题以外的资料可直接供题、提供事实与情境、暴露误区或支撑原创；不得仅作装饰性引用。
4. **题目身份透明。** 标明原题、改编或原创；原题须逐项忠于原文，改编记明改了什么及对解与难度的影响，原创列出知识依据、情境依据和质量锚点。原创不需要伪造原题题号，引用一本书也不意味着该书出现过这道新题。
5. **范围和难度不可偷换。** 基础练习、阶段测与完整模拟分开；阶段内容以已学证据为界，拓展明确标识。完整模拟按核实后的目标规则覆盖考纲。相邻卷型和旧资料可以转用其适用内容，须逐项映射，不能整卷套用。估时、预期难度与实测数据分开；没有考生数据就不编造正确率、区分度、信度或预计考分。
6. **先答案与评分，再发布。** 仅有模型口头“已检查”不构成审校证据。每题须完成不看拟定答案的复解、适用的交叉核验、替代答案检查和评分点核对；记录实际做过的方法、关键结果与限制。同一模型复解如实称为复解，不能冒称另一位教师或专家审定。
7. **缺口不能用发挥填平。** 可缩小到有依据的题目、替换材料或交付带缺口的草稿；核心事实、唯一性、评分或正式考试规则仍有争议时，不把它发布成正式测评。需要用户补充时只问影响本次命题的缺项，继续处理独立部分。不得谎称读过全文、运行过程序或完成过审校。

## 命题流程

### 1. 固定测量任务

读取当前请求与实际记录，确定科目/卷型、目标考季、练习或测评用途、范围、学习进度、题型、题数、分值、时间和允许工具。已知信息不重复追问；未指定的低风险练习参数可以给出明确假设。目标科目、关键范围或全真规则不明时，先核实，不猜。

按任务使用原题、改编或原创，可混合；不要把“出题”默认解释成全文复刻真题，或解释成完全脱离资料的自由创作。复测应保持所测能力，改变能排除记忆作答的关键情境与条件。

### 2. 建立资料贡献表与质量锚点

按资料角色检索，不只搜“真题/试卷”。围绕目标知识点，考虑概念与机制、教学路径、实际情境、典型误区、语言或图表材料、学情与操作约束；选择能作出实质贡献的资料并读取相关内容。无需为凑种类把不相关材料塞进卷子。

记录 `资料 → 读到的位置 → 对哪些题贡献了什么 → 适用边界`。同一本书的多个排版、同一真题的多个转载不算独立来源。用真题建立质量锚点，不要求每道新题都能找到长得相像的真题；无同类题时可对照能力、设问和严谨性。没有可读真题时可做标明限制的练习草稿，不能自称“已按真题校准”。

### 3. 先列蓝图，再写题

每个题位先写：考查主张、必须出现的可观察作答证据、对应任务、考纲/已学范围依据、取材角色、认知操作、真题质量锚点、题型、分值和估时。主观题尤其要说清“怎样的回答能证明会了”。

整卷检查知识覆盖、能力覆盖、信息和计算负荷、重复考点、题间泄题、时间及评分总和。综合题可测多个知识点，但不能无理由堆叠技巧。难度配比随用途和锚点确定，不硬套通用比例；训练卷与考试结构有偏离时说明原因。蓝图留存后再填题，修改蓝图说明理由，不能为凑现成题倒推目标。

### 4. 命题并完成评分

题干自足，保留解决问题必需的图、表、符号、单位、前提与约定；把非考查对象的陌生背景解释清楚。选项应有基于概念边界或常见误解的理由，不能靠语病、长度、绝对词或排版猜答案。每个选项分别验证；多选按目标考试规则处理。

同步写出可复现的解答、等价答案、评分点及分值。评分依据应识别有效作答证据，不能只匹配标准答案的措辞。原题配套答案也可能有误；矛盾未解决就隔离该题，不改写条件来迎合答案。

### 5. 复解、整卷检查与交付

先暂时遮蔽拟定答案，只凭题面求解；再用原文、第二种方法、边界/反例、枚举或程序等适用方法交叉核验。数值抽检不能冒充证明，程序通过不能替代题意和评分审查。改动条件、选项或答案后，重做受影响核验。

按 [发布检查](references/work-products.md) 保存题面、答案评分与审校依据；需要时用 `scripts/check_paper.py` 核对结构和算术，真实运行才记为通过。检查器不判断知识真假、来源是否真的读过或题目是否达到真题质量。

有阻断项就保留草稿并说明。没有阻断项才发布；练习得分只能解释为本次范围内的表现，不能外推正式考试成绩。发布后的勘误另发修订版本，保留原卷和原评分，说明对已提交答卷的影响。
