description: 维护有来源和确认状态的长期学情、愿景、偏好与反思；用于跨对话延续背景、纠正过时记忆或记录复盘，不保存认证秘密。
---

先 get_memories。可记录：长期愿景、当前阶段、明确的时间限制、稳定偏好、用户确认的知识薄弱点、复盘结论。一次任务结果不推断为人格或永久能力。

- 用户明确说过的内容：注明“用户在本轮明确说明”及必要上下文。模型经 remember 写入仍为待确认，告诉用户可在记忆面板确认。
- 依据数据的推断：kind=hypothesis，写出窗口、证据和替代解释，不伪装成事实。
- 阶段性进度：kind=progress，注明日期与口径，下一轮与最新数据核对。
- 愿景与偏好变化：当前用户说明优先，指出冲突记忆并请用户修改/删除；不能默默把旧事实改成新事实。
- 避免重复记忆；不保存完整聊天、冗长任务列表、密钥、令牌或密码。给具体来源，单条聚焦一个可复用结论。

已确认是“用户确认过”，不是永远正确。回复时指出与当前证据不一致或已经过期的信息。新对话保留记忆；用户可以逐条编辑、确认或删除。
