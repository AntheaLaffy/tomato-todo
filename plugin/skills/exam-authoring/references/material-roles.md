# 各类资料的命题价值

这是资料用途表，不是“最值得参考”清单。**真题承担命题质量基准；题材和知识来源面向整个资料库。** 同一资料可以同时贡献概念、情境、误区和评分依据，不必每类取同样数量，也不因未被本卷采用就判为无价值。

## 按贡献取材

| 资料类别 | 可以贡献什么，怎样用于命题 | 采用时核对什么 |
| --- | --- | --- |
| 考纲、考试说明、官方样题与改革文件 | 建立可考范围、目标能力、卷型及操作规则；改革说明能提示新的任务形式和跨模块能力 | 发布机构、适用年度、正文与修订；解读与规范原文分开。名为“大纲”的习题集仍按内容识别 |
| 真题及其解析、评分材料 | 命题质量基准：重要概念怎样被问到、怎样组织条件、推理深度、干扰项、语言密度和评分尺度；也能直接供题、作比较或保留为测量卷 | 同科目/卷型/版本，真题正文与机构参考答案的身份，是否已做或见过；历史频次不能证明未来必考 |
| 教材、参考书、理论专著 | 概念定义、定理条件、机制、证明、边界与反例；把文字说明、推导、例子或章间关系转成解释、辨析、建模和迁移题 | 术语约定、前置知识和目标考纲；大学教材内容广，不等于都在考纲内 |
| 讲义、板书、PPT、课堂例题与教学活动 | 教师怎样拆解困难、先后依赖、对比结构与关键中间步骤；用于递进练习、补全推理、方法选择和跨表示转换 | 实际读到的教学内容及已学位置，不能由课程标题推断学完；讲义少量例题不意味着另有整本作业 |
| 习题册、章节测试、专项练习、做题本 | 题型变体、细粒度技能、参数变化和局部陷阱；组合成训练阶梯、对照题、迁移题和专题诊断 | 原题、答案及勘误的配套关系；题本是否只有题目或空白页；排版变体不增加题目多样性 |
| 模拟卷、月考、押题卷 | 考点组合、原创情境、设问变形、整卷节奏与压力配置；可拆取材料、改进不佳设问或比较不同组合 | 逐题真实性和正确性仍需审校；名师、押题标签、机构年份都不能自动证明预测或难度 |
| 笔记、思维导图、知识总结与速记表 | 知识之间的联系、压缩表达与遗漏；用于概念图修补、比较辨析、条件追问和从简表恢复完整推理 | 区分作者结论与可靠知识；笔记错误可以作为“待纠错观点”，不能直接充当正确答案 |
| 错题、历史答卷、订正、批改与复测 | 已观察到的误解、程序失误、漏条件与迁移失败；用于干扰项、对照任务、错误诊断和延迟复测 | 只用可见作答支持的误区；自述、推测和确认事实分开；不能编造学生心理或以原题重做证明迁移 |
| 答案册、详解、手稿与勘误 | 解法分歧、评分分解、隐藏前提及错误来源；用于替代解、论证补全、找错改错和审校反例 | 对应版本与题号，实际改了什么；多个转载同一解析不是独立复核。纠错题须明示材料中可能有错 |
| 英语词汇书、词表、例句、搭配与词典 | 一词多义、语境义、搭配、词形与词族关系；用于语境选择、释义辨析、改写和词汇迁移 | 义项与例句、自然用法及歧义，不能随机凑四个同义词；阶段词汇训练不冒充英语一完整阅读测量 |
| 阅读材料、外刊、新闻、科普与专题文章 | 新鲜但可核实的情境、论证结构、语篇关系、作者态度、数据与图表；用于全新阅读题或跨学科建模 | 原文完整性、段落边界、发布时间与改写范围；每题文本证据必须充分，不能依赖课外常识猜作者态度 |
| 长难句、语法与翻译材料 | 作用域、指代、逻辑连接、结构歧义与意义单位；用于结构分析、语义比较、翻译和改写 | 上下文、原文及可接受表达；自然翻译通常不唯一，不能按参考译文逐字匹配 |
| 作文、范文、书信、图画/图表及模板 | 交际任务、内容要点、读者关系、论证、语域与信息转述；用于新的写作任务、局部修订、论据选择 | 写作情境和目标卷型；范文不是唯一正确答案，模板熟练度不能取代真实表达能力 |
| 背诵材料、答题逻辑、考点清单 | 核心术语、原理间关系、回答组织和材料到原理的连接；用于概念检索、观点辨析和材料分析 | 简写的完整语义及版本；不把背熟某机构原句作为唯一得分条件 |
| 时政、历史文件、政策、事实案例 | 理论应用、时间与条件分析、原理在实际情境中的边界；可构建新材料和比较问题 | 原始出处、事件日期、发布/生效日期及目标考季；旧时政可作历史情境，不伪装成当季热点 |
| 专题合集、开源仓库、程序、实验与工程文档 | 实际数据结构、系统状态、协议行为、实验观察与失败案例；用于追踪、算法设计、性能模型辨析和系统综合题 | 文件在合集中的职责、可复现条件、源码版本；README是入口，配置或许可证不能被误认成学科论证 |
| 音频、视频、动画、图像与演示 | 发音和重音、课堂推演过程、动态机制、空间关系、可观察现象；转成图表解释、过程追踪或情境材料 | 必须实际听/看相关片段，记录时间码/帧位置；同名音频不证明与文字逐句对应。正式考试不考听力时，不擅自新增听力分值 |
| 课程档案、课程清单、材料说明与习题对应表 | 确定学到哪、教材与讲次如何对应、作业形式及可用配套材料；指导题目粒度和前置知识 | 清单证明课程存在，不证明学会；查物流或找讲义的视频贡献的是操作入口，不是学科知识 |
| 学情档案、个人说明、学习进度与课表 | 确定诊断起点、可用窗口、需避开的占用、无障碍或表达需求；用于范围、题量和时长适配 | 私人数据只在当前授权范围使用；成绩、任务完成、计时、订正与独立复测分别解释；不写入通用技能或安装包 |
| 月度计划、学习计划、记忆与复习表格 | 阶段目标、知识先后、复习间隔、覆盖追踪与测量安排；用于蓝图采样、延迟复测和任务负荷控制 | 计划是意图，不是已学证据；记忆曲线介绍不自动证明某种固定间隔适合该学生 |
| 经验帖、备考指南、学习方法与复盘 | 生成待检验的易错点、策略假设、训练情境和时间分配问题；可设计小型诊断验证其是否适用 | 年份、基础和个体条件；经验不能证明命题规则、成功因果或学生必然的困难 |
| 索引、来源记录、资源入口、下载说明与附件 | 找回原件、配套答案、版本和勘误，追踪材料关系；打印与文具资料可帮助组织纸面测评 | 目录不能替代正文；广告和推荐不能当官方要求；不因链接存在就声称已取得或读过文件 |
| 学习工具、应用、表格与交互练习 | 提供词汇检索、计时、答案记录、数据整理或验证环境，也可提取有明确出处的学习内容 | 功能描述与实际可用性分开；不为了命题安装/运行来源不明软件，未经查看不推测工具内部题库 |
| 壁纸、铃声、插画等辅助素材 | 在用户需要时辅助封面、任务情境、节奏提示或可读性，提升测评使用体验；图像本身也可作明确的观察对象 | 不强迫每份材料都贡献学科结论，不泄露私人目标，不让装饰造成难度或答案线索 |
| 待确认、匿名或范围不明材料 | 可发现尚未分类的概念图、题材、题目和资料关系；先查看内容识别身份，再判断能承担的角色 | 未读或无法辨认就保持待确认；未知来源不妨碍探索，但未经核验的关键事实不能进入正式答案 |
| 相邻科目、其他考试、旧版与补充材料 | 不同表示法、内容组织、应用情境、迁移任务和反例；适用部分可以成为很好的新题材料 | 显式映射当前目标：保留什么、舍去什么、补什么条件；不因放在“补充”就忽略，也不直接沿用其范围与分值 |

## 把材料转成题目，而不是堆引用

对每份选用材料依次写清：**读到了什么 → 想判断学生会什么 → 什么作答能支持判断 → 什么任务能引出这种作答 → 怎么判分。** 再用真题质量基准审查这道任务的设问与严谨性。这种对应关系比材料来自哪个文件夹更重要。

例如，教材的某个定理条件可以产生“条件拿掉后是否仍成立”的反例题；课堂图示可转为文字/公式互译题；真实文章的论证可以产生由上下文支持的推断题；实验记录可转为状态追踪题；错题里观察到的混淆可成为干扰项。它们都不需要先在真题中出现过相同情境。材料不足时缩小主张，不能让生成的故事补上未经验证的事实。

审校时追问每个来源对本题究竟承担哪项贡献。只有“参考了教材/真题/外刊”而没有位置与具体作用，视为未完成取证。反过来，不要求每类资料都入卷，也不规定“非真题占比”；按目标选用，并解释本卷为何需要这些角色。

## 方法依据的适用边界

- [SRI：Evidence-Centered Assessment Design（2005）](https://www.sri.com/publication/education-learning-pubs/evidence-centered-assessment-design-layers-structures-and-terminology-padi-technical-report-9/)：用于组织“考查主张—作答证据—任务”的对应关系，不提供中国考研科目范围或题型规定。
- [NBME：Item-Writing Guide（所查PDF为2024年10月版）](https://www.nbme.org/sites/default/files/2021-02/NBME_Item%20Writing%20Guide_R_6.pdf)：借鉴设问清楚、选项合理、去除无关难度与答题线索的审校方法；医学案例和单选偏好不迁移为考研规则，不排除目标考试要求的多选、填空、证明或写作。

这是本技能对通用方法的应用。正式科目的规范与质量基准仍取自适用考纲、考试文件和真题；不要声称这些方法已经为本卷提供了统计效度或专家认证。
