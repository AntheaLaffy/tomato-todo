# 应试教学与批改

先读取已安装的 `tomato-todo` 技能，连接当前实例并获取学情。对话在 DSH 中进行，课程、测评、批改和进度保存到番茄 Todo。正式操作前读本技能仓库的 [教学字段快照](../tomato-todo/references/teaching-contract.md) 核对字段；本技能补充 DSH 入口，不替换运行时契约。

## 备课与讲解

核对科目、目标考试及年份、考纲、当前实际学习位置、已有材料和本次目标。正式启用应试模式还需本项目愿景、具体目标、考纲、真题和模拟题。缺口按实际情况说明，不编造官方范围，也不把目标学校直接换算成训练强度。版本敏感的考试规则查证适用年份的原始来源。

先读材料原文和有时间、来源的学情证据，再确定讲解起点。已有课程逐章匹配考纲；只解释相关知识和难点，给学生尝试、说明理由和反馈的机会。学生尚未作答时不把给过例题当作已经掌握，不为一次简单讲解强行创建完整学期。

正式学期计划保存基线、阶段目标、资源、依据和排期理由，更新递增 revision。正式课程绑定本项目学期，固定 45 分钟；完整学习日跨项目合计上午 4 节、下午 2–4 节，保留课间，遵守核心上限与冲突检查。零散增排不为凑课时填满一天；固定需专心课程、吃饭午睡及用户作息优先。需要排期时使用 `study-planning`。

## 作业、周考与命题

出题、组卷、复测时同时读取已安装的 `exam-authoring`，执行资料贡献、命题蓝图、逐题依据、答案、替代解法、带分值评分点与不看拟定答案的复解。真题校准质量，教材、讲义、笔记、错题和外刊按实际用途取材。保存实际审校依据再发布，不以口头“已复核”代替验证。

- 基础作业只覆盖有证据支持的已学范围，拓展题标记 extension。来自已下课课程的作业引用实际课程；来自已完成学习任务的作业先读取 completedTasks 中的不可变快照及最新学情，设 `lessonId=null`、`taskId=原任务ID`。未知范围先核实。
- 先看固定课程、可用时间和近期负荷，课程量不重复算成作业。180 分钟是全科作业供给的聚合基线，不是每科配额或最低任务量；用户时间表与减量要求优先，不追补差额。默认晚间 19:00–22:00 服从用户实际作息，到收工时间如实提交未完成部分。
- 阶段周考覆盖当前学期已学内容；全真模拟按核实后的完整规则，分别使用 weeklyExam 与 mockExam。跨项目协调周末窗口，替换相应课程和作业负荷，保留未练过的试卷用于测量。
- 学生试卷与答案评分分开，说明时长、允许物品、闭卷与停笔规则，提醒打印题面和答题卡。考试中不提供答案或解题提示。逐题 HH:MM 是完成时刻，跳题时不能据此推算每题耗时；软件记录不证明线下已经停笔。

已发布的题面、答案和评分标准不可原地改写；有错发布新 ID 的修订包并说明对既有提交和批改的影响。

## 批改、订正与复测

先读取对应发布版本的题目、答案、评分点和学生原答卷。逐评分点记录得分及具体答卷证据，使用等价解法，不能临场增设扣分项、重复计分或超分。照片/OCR 不清时标记 `needsReview=true`，指出需补充的位置，不将无法识别判为错误；未覆盖但合理的新解法进入复核。新批改使用新 ID，保留原记录。

错因分析写清误判机制、证据、纠正动作、下次检查信号与复测日期。尚未与学生核实的错因 `confirmed=false`，不编造心理过程。订正按原题和原批改检查；通过订正不等于掌握，须用关联原批改且能排除记忆作答的独立复测验证。

复盘结合近期课程、实际计时、提交、正式成绩、订正与复测，挑少量可执行行动。使用 `study-diagnosis` 分析原因；正式复盘引用本项目实际 gradeIds，事件复盘日期遵守 sourceId 对应日期，不用与现实冲突的固定钟点。

## 保存与延续

文件先写到项目授权目录，再登记资源和保存正式记录；学情用 `tomato_education` 的 `recordProgress` op 追加，来源保留 assistant。用户在对话中明确确认的学习事实可再独立 `confirmProgress` op；不确定信息保留待确认。不要改写旧记录或用勾选任务代替掌握证据。

只在确实接手了具体教学事件且实际产物已保存时用 `tomato_education` 的 `finishEvent` op；失败或用户停止不伪装完成，用户要求继续时按当前状态 `retryEvent` op。普通对话不顺手领取全部事件或另建定时调度。运行时断开时保留草稿，恢复后核对最新记录再提交。
