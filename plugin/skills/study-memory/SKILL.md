# 延续同一份学习记忆

先读取 `tomato-todo`，用 `tomato_get_context` / `tomato_get_education(collection=progress)` 核对现状。番茄 Todo 没有独立的「记忆」集合，跨对话的长期学情就是 progress 记录；对话助手不为相同学情另建一份平行记忆库，也不声称会自动记住未保存的对话。

## 记录什么

只保存有跨对话价值的长期愿景、当前阶段、明确时间限制、稳定偏好、已确认的薄弱点和复盘结论。一次任务失败不能推出人格或永久能力；不要保存完整聊天、冗长任务列表、完整答卷、账号密钥、令牌或密码。

长期学情/结论落到 progress 记录，单条聚焦一个结论，写清来源日期、相关项目/任务/测评或文件位置，避免重复。

- 用户明确说过的事实：`source` 注明本轮明确说明及必要上下文；用 `tomato_education` 的 `recordProgress` op 保存后仍为待确认，告知用户可确认，不伪造已确认状态。
- 模型推断：用 `recordProgress` 记录为待确认（`source=assistant`），注明统计窗口、证据和替代解释，不升级成事实。
- 阶段变化：记录新 progress 并在 `position`/`evidence` 注明日期与口径，下轮核对最新数据；长期学情不替代正式逐条学情。
- 愿景、偏好或旧结论变化：当前明确说明优先；指出冲突，按实际可用接口处理，不默默覆写旧事实。番茄 Todo 无独立记忆面板，偏好类事实写进 progress 或由对话延续；不直接编辑私有 state.json。

## 正式学情与记忆分开

实际学习位置、依据、状态和下一步通过 `tomato_education` 的 `recordProgress` op 追加，保留 assistant 来源。用户在本轮明确确认的学习事实，可以再独立 `confirmProgress` op；不确定内容仍待确认，不原地覆盖旧进度。此操作前读本技能仓库的 [教学字段快照](../tomato-todo/references/teaching-contract.md)，不能用记忆文本替代课程、提交、批改或复测记录。

“已确认”表示用户确认过，不表示永远正确。读取时检查日期、阶段和新证据，发现过期或矛盾就说明。应用断开时可整理待保存内容，明确尚未写回；只在工具成功后说已保存。
