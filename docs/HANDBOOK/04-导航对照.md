# 附录：导航对照（与 CODEMAP 对接）

> 附录 ｜ 最后核对：v0.13.0（2026-11-07）｜ 更新时机：新增/删除章节、拆分文件、或 CODEMAP 任务指南调整时
>
> **这是给维护者用的附录，不是手册正文。** 手册正文（06–95 章）讲的是「它怎么运转、有哪些规则」，读者不需要先知道文件名；
> 找文件、找符号、确定阅读顺序看本页与 [CODEMAP](../../CODEMAP.md)。

[CODEMAP](../../CODEMAP.md) 是**面向改动的一线导航**（任务 → 目标文件、子目录地图）。本页是它的手册侧对照：把「哪一章」「哪些文件」「什么顺序读」三者对上，供维护与评审时查。

- **从任务出发**：先在 [CODEMAP 任务指南](../../CODEMAP.md) 匹配 Target 与 Also Check，再回到下表找对应的手册章节看实现说明。
- **从代码出发**：读到某个文件不明白时，用下表反查章节；每章的 **C 段** 讲机制，附录区块给出该章涉及的文件与推荐阅读顺序。
- **改完代码**：任务指南与手册章节一起改。改了实现不改手册，等于把参考手册变成过期资料。
