# 附录：导航对照（与 CODEMAP 对接）

> 附录 ｜ 最后核对：v0.12.0（2026-11-02）｜ 更新时机：新增/删除章节、拆分文件、或 CODEMAP 任务指南调整时
>
> **这是给维护者用的附录，不是手册正文。** 手册正文（10–26 章）讲的是「它怎么运转、有哪些规则」，读者不需要先知道文件名；
> 找文件、找符号、确定阅读顺序看本页与 [CODEMAP](../../CODEMAP.md)。

[CODEMAP](../../CODEMAP.md) 是**面向改动的一线导航**（任务 → 目标文件、子目录地图、大文件的 `.analysis.md` 索引）。本页是它的手册侧对照：把「哪一章」「哪些文件」「什么顺序读」三者对上，供维护与评审时查。

- **从任务出发**：先在 [CODEMAP 任务指南](../../CODEMAP.md) 匹配 Target 与 Also Check，再回到下表找对应的手册章节看实现说明。
- **从代码出发**：读到某个文件不明白时，用下表反查章节；每章的 **C. 代码路径** 给出推荐阅读顺序，**D. 关键定义与调用链** 给出该文件里的关键结构与主要链路。
- **改完代码**：任务指南与手册章节一起改。改了实现不改手册，等于把参考手册变成过期资料。

### 10-锁与专注保护

**入口**：先从 `guard.rs` 的 `allowed()` 看判据（三种模式与精确匹配都在这一处），再看 `enforce()` 怎么抢回焦点；严格模式的拒绝在 `lib.rs` 的 `strict_protected()`。

| 顺序 | 文件 | 关键符号 |

| 1 | `crates/guard/src/guard.rs` | `select_linux_backend`、`allowed`、`Window`、`LockWindow`、`Backend`、`Desktop`、`linux_backend`、`detect_backend` |

调用链：
