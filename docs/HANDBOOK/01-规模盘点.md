## F. 怎么用这些数字

1. **对外讲规模时只引这一页**：数字会变，口径固定在这里，别在别处另算一份。
2. **「3 万行」怎么来的**：代码合计 51,833 行，其中 Rust 与界面各占一块，测试与规则是主要增量。
3. **被问「是不是过度设计」时**：翻到 C 表——最大的文件和最大的一块是规则与测试，而不是界面代码，这本身就是答案。
4. **发布前跑一次**：`pnpm run handbook:stats`，然后把手册页眉的版本与日期一起更新。
