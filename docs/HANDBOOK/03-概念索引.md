# 概念索引

> 手册章节 ｜ 最后核对：v0.13.0（2026-11-07）｜ 更新时机：新增概念、改术语或调整章节职责时

按词找人。左边是你在代码、界面或讨论里会遇到的词，右边是把它讲清楚的那一章。设计层面的「为什么」在 [../DESIGN.md](../DESIGN.md)，文件字段在 [../PLAN_FORMAT.md](../PLAN_FORMAT.md) 与 [../BACKUP_FORMAT.md](../BACKUP_FORMAT.md)。

重构后有两套名字要分清：**域**（任务、锁、课表……，在 `packages/core/`）与**进程**（runtime、guard、插件，在 `runtime/`、`crates/guard/`、`plugin/`）。同一个词常常横跨两层，索引里给的是讲得最全的那一章。
