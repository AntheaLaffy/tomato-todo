# 旧版功能清单（重写补全基准）

旧版番茄 Todo v0.12.4 的功能面记录，来源：用户截图（各页面全貌）+ 旧源码
（src/main.ts 的页面/对话框、src/types.ts 的 Settings/Task、crates/core）。

用途：新架构逐项核对。状态标记：✅ 已实现 · ◐ 部分实现 · ⬜ 未实现 · ➡ 由 DSH 替代。
新架构 = DSH 插件（`plugin/src/client/`）+ Node runtime（`runtime/`）+ Rust guard。

## 2a. 沉浸式专注模式 ✅

- 顶部状态徽章：「应用白名单保护中」（或界面锁定中 / 休息锁机中 / 自由专注）✅
- 居中大计时 44:59 + 「此刻，只做这一件事。」✅
- 当前任务名（语法加强 Day05（下）：讲义应用与回忆）✅
- 白名单提示：「允许使用 6 个应用，其他应用会被切回」✅
- 「查看今天日程」入口 → 切到主视图本周日程 ✅
- 「有急事，提前结束」链接 → 打开 2b 结束确认对话框 ✅
- 「选择背景音」入口（雨声/棕噪音/静音，音量来自设置）✅
- 底部 toast 提示（「已选择任务，准备好就开始吧」）✅ notify
- 退出沉浸模式（minimize 按钮返回普通界面）✅

## 2b. 专注结束确认对话框 ✅

「要结束这一轮专注吗？」：

- 说明：本轮已做完可提前完成番茄并进入休息，专注时长按实际用时记录；任务仍需手动勾选完成；临时中断请选择「结束并解锁」，本轮不计为完整番茄 ✅
- 输入框：输入「结束专注」确认中断 ✅
- 按钮：「提前完成」（完成番茄进休息）/「结束并解锁」（中断不计完整番茄）✅
- 严格模式：两键都禁用并提示，语义由 core 判定，客户端不提供旁路 ✅
