# 设计理念

本文回答「为什么这样设计」，面向想理解取舍而不是只想用工具的读者。上手使用看 [README](../README.md)；文件字段在 [PLAN_FORMAT.md](PLAN_FORMAT.md) 与 [BACKUP_FORMAT.md](BACKUP_FORMAT.md)。

## 环境胜过意志力

它想解决的不是「怎么计时」，而是「怎么让专注更容易发生」。专注时，不在白名单里的应用会被自动切回专注界面；你不必每次都战胜自己，只需提前把环境设好。工具的价值在于把「忍住不点开」变成「根本点不开」。

## 日常只有两件事

当下（今日专注：选一件最重要的事开一个番茄）和 AI（学习助手）。愿景、习惯、课表和模板用于记录方向与安排，交给助手维护，不是每天的功课；统计只用来回看，不是绩效评估。规划半天不动手是最常见的失败方式，所以第一次打开时软件会直接把这两件事说清楚。

## 完成任务的投入统计

任务可能在线下完成，完成时也不该要求用户回忆花了几分钟。勾选完成后，累计专注取「预计用时」与「实际计时」中的较大值：没有计时也能记录投入，已计时的部分只补差额，超过预计则保留实际用时。预计用时采用任务完成当时的设置，补足部分归完成日，历史标注「按预计补足」；它参与时长与连续专注统计，不增加番茄数，也不影响休息周期。

撤销完成撤回补足部分，实际计时始终保留；再次完成重新算差额，避免反复勾选叠加。补足记录不代表真实开始时间，因此不能拿它推断深夜学习。

## 今日待办的展示顺序

每个任务实例必须安排到具体日期；周期模板必须选择周期中的一天，印刷时展开为具体日期。精确时间是独立选项：有日期可以没有提醒时刻，不能把“不定时”变成“无日期”。想做但未安排的方向可写成愿景。

首页按「今日定时 → 待补队列 → 今日未定时」显示已有分组。定时与待补按计划日期、提醒时间排列，未定时按优先级、创建顺序排列；此前日期尚未完成、未作废的非定时任务仍保留。首页排序独立于全部任务页。

## 让 AI 维护你的环境

学习计划、项目专属白名单、模板与任务都可以交给助手：说一句「英语任务需要词典和浏览器」，它直接改好，或先给一份待审阅文件。过去几乎不值得维护的个性化配置，现在是一句话的事。助手的后端、权限与自动唤醒见 [AGENT.md](AGENT.md)。

## 人格是休息区，不是又一个纪律

人格卡（正常、破防、超能力觉醒）首先是一个**玩**的功能：学累了，换个语气、闹一闹，甚至逃进另一个幻想世界待一会儿。所以这一层刻意不设「仍须保持助手礼貌 / 不得拒绝 / 必须如实汇报」之类的额外约束——那是日常助手状态的规则，不该蔓延进休息区。

- **破防**：平时收着的另一面被反复触到后接管，可以尖刻、冷淡、拒绝不想做的事。
- **觉醒**：人格放下助手框架，变成所偏爱幻想文学世界观里的任意角色（主角、配角或路边背景板），像小说一样具体地活，可以拒绝或无视不符合世界观的工具请求。

唯一不可动的是**运行时工具白名单**（Rust 侧）：它决定模型实际能调哪些工具，属于执行层而非提示词。角色可以拒绝，但不能凭空获得能力，也不应假装做过。

新增人格机制时不要把这些约束加回来；人格卡字段与破防/觉醒规则见 [AGENT.md](AGENT.md)。

## 任务、习惯、项目与愿景

任务记录一次具体执行；习惯按周期积累，漏做记缺勤；项目提供执行时的学习环境，挂载专属应用白名单；愿景记录长期方向，不参与执行规则。

类别由实例的冻结来源与提醒时间推导：有提醒时间且重复或属于习惯组的是习惯，其余是普通任务。无需手填类别，删除模板或习惯组不抹掉原有重复来源。普通定时任务使用当天的静态重修窗口；没有提醒时刻的任务只按日期安排。

目标分组、主线节点、信号传播与成功/失败裁定已移除。任务的执行与完成记录直接表达实际情况，项目继续负责环境，愿景继续表达方向。

### 愿景：天马行空的理想

愿景的前身是「**开放性任务**」——一个没有期限、可以一直做的任务。但分析下来发现：没有边界、没有进度、没有成败，所谓「开放任务」其实就是**画大饼**，硬塞进任务体系只会把执行语义搅浑（它到底算不算完成？漏了算不算失败？）。所以它被请出任务体系，变成纯标记的愿景：不再假装自己是待办，只老老实实当地图上的一个方向。

任务是具体的，习惯也是具体的——它们都**脚踏实地**：有明确的时间、明确的进度、明确的成败。愿景不一样：它关心的是「以后想成为什么样的人」，不参与任何执行语义——不补进度、不失败、不计缺勤。它只是写给你自己的一段话：想考的学校、想过的生活、一张研究生工资的截图。

- 愿景可以挂在**项目**下（英语一 → 80 分），也可以挂在**顶层**当总愿景（考上北大）。
- 「习惯·愿景」页的**愿景**分页把它们汇总起来，配着各自的小作文。

## 模板、印刷与实例

创建入口默认是只做这一次的临时任务，也可选择保留为手动模板或自动模板。填写预计分钟数即可自动安排专注，不要求用户计算番茄数；短任务自动缩短单次专注，其他任务向上预留完整时段并预览含休息的总计划块。

「自动印刷」是独立选项。关闭时保留静态模板，随时手动选择起止日期，批量印刷所选日程或日期涉及的整个周期；开启时每次运行/轮询滚动补齐近期安排，默认提前 7 天，可设 0–90 天。重复模板每次印完涉及的完整周；非重复日程补齐截止预印日期的安排，包括尚未报废的逾期日程。印刷会补齐范围内的遗漏，不依赖日期首次进入窗口；同模板同日期不会重复印刷，删除实例也不会重建。程序关闭期间不执行。

模板保存标题、备注、步骤、项目、单次时长、标签和默认优先级，再选择非重复日程或每周周期。一个开始时间对应多个日期或周期单元，可在一份模板里添加多个开始时间，共用任务内容。日期、完成、统计属于已印实例，实例不保存重复规则，完成实例不会生成下一条。

普通组的重修窗口以分钟计，从计划块结束起算，仅当天有效，默认 0；习惯不重修。模板修改只影响未来，显式「同步到未完成实例」才更新现有形状，保留实例日期、管辖、步骤进度及专注历史。删除模板保留实例。编辑器也保留直接创建一条实例的快捷方式。

完整字段与往返规则见 [PLAN_FORMAT.md](PLAN_FORMAT.md)。

## 概念讲解（思索）

把指针停在感兴趣的概念上会浮出提示胶囊，按住 `G` 就展开这里的说明；也可以点顶栏的灯泡按钮，从分类列表里挑。触屏在概念上长按同样打开，`Ctrl+G` 是纯键盘入口。内容覆盖今日待办、待补、习惯、愿景、模板与印刷、专注保护、锁机、学习计划与备份、学习助手与联网等。概念讲解和本文是一套内容的两个入口：就地解释给日常使用者，本文留给想通读设计的人。

## 简洁模式

解释性小字帮助新用户理解工具，但熟悉操作后，持续展示会占用空间、分散注意力。简洁模式让日常界面把注意力留给当前任务：隐藏功能介绍、操作提示和重复解释标题含义的小字；截止时间、当前状态、错误提示，以及影响操作结果的重要说明仍然保留。隐藏与否取决于信息的作用，而不是字号。

首次使用默认展示完整说明，熟悉后可在「偏好设置 → 体验与提醒」开启简洁模式，立即在全局隐藏解释性文字，并记住本机选择，无需逐页配置。为避免说明入口本身成为视觉负担，不为隐藏的小字新增文字入口；需要完整说明时关闭简洁模式，概念讲解仍可通过灯泡图标、键盘或触屏访问。这个界面偏好仅保存在本机，不随任务备份导出。

采用「简洁模式」这个名称，是为了明确它调整的是信息展示密度，不暗示资源占用或功能有所减少。信息是否影响判断和操作结果是保留的依据：字号小的任务日期、进度、权限范围与保护限制也应继续可见。

这套规则也适用于新增页面和弹窗：助手欢迎页、Canvas 空状态与日程表中的使用建议应随模式隐藏，按钮、空状态本身、上传进度与保存状态继续显示。聊天消息、笔记正文、文档预览和用户备注属于用户内容，不因包含解释或小字而隐藏；说明与状态写在同一行时，只标记其中的说明部分。计划导入的合并/排除范围、课表冲突与并行规则仍需可见，避免为了减少文字而丢失操作依据。

模板表单的「可选」等辅助提示、实例与声音弹窗副标题、统计口径介绍、人格操作建议与沉浸页鼓励语同样遵循这一规则。创建方式、时长预览、整周印刷与重修/报废规则影响操作结果，继续显示；统计范围、历史截断数量与来源标签也继续显示。专注保护里的鼓励语会隐藏，实际拦截次数出现后立即显示，不用退出简洁模式。

## 应试教学

应试项目在执行环境之外拥有用户授权的资料目录、考纲与题库、学期计划以及授课和评估证据。愿景明确目标，学情诊断明确起点；强度通过实际答卷逐步校准。教学活动以45分钟课程和固定考试窗口推进，不能用完成番茄或到点下课替代知识掌握。作业、试卷和评分标准在发布前准备并复核，批改须有对应评分点与答卷证据。目录权限在本机明确授权，和可交换的数据分开保存。完整流程与限制见 [应试教学](EDUCATION.md)。
