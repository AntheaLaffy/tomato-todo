# 设计理念

本文回答「为什么这样设计」，面向想理解取舍而不是只想用工具的读者。上手使用看 [README](../README.md)；主线节点的完整语义在 [NODE_DESIGN.md](NODE_DESIGN.md)，文件字段在 [PLAN_FORMAT.md](PLAN_FORMAT.md) 与 [BACKUP_FORMAT.md](BACKUP_FORMAT.md)。

## 环境胜过意志力

它想解决的不是「怎么计时」，而是「怎么让专注更容易发生」。专注时，不在白名单里的应用会被自动切回专注界面；你不必每次都战胜自己，只需提前把环境设好。工具的价值在于把「忍住不点开」变成「根本点不开」。

## 日常只有两件事

当下（今日专注：选一件最重要的事开一个番茄）和 AI（学习助手）。目标、愿景、习惯、课表、模板这些是**任务的容器**——给助手落笔用，不是每天的功课；统计只用来回看，不是绩效评估。规划半天不动手是最常见的失败方式，所以第一次打开时软件会直接把这两件事说清楚。

## 让 AI 维护你的环境

学习计划、项目专属白名单、模板、目标与任务都可以交给助手：说一句「英语任务需要词典和浏览器」，它直接改好，或先给一份待审阅文件。过去几乎不值得维护的个性化配置，现在是一句话的事。助手的后端、权限与自动唤醒见 [AGENT.md](AGENT.md)。

## 任务、目标、习惯、项目与愿景

日常的「事」叫任务。任务之外还有五种容器，分两个轴：**执行语义**（目标、习惯）和**环境语义**（项目），外加一个不参与执行的**方向标记**（愿景）。

### 类别由管辖与时间/重复推导

用户不手填类别，程序从已有信息推导：

- 属于某个目标 = **主线管辖**，配对节点尚未裁定时可待补，裁定后报废；
- 不属目标、**有提醒时间且重复** = **养习惯**，过期后从今日待办移出并计一次缺勤；
- 其余（无提醒、定时但不重复、不定时的重复）= **普通番茄钟**，用静态重修窗口。

同一个任务可以同时属于某个项目和某个目标/习惯：项目负责环境，目标或习惯负责执行语义。

### 目标组承载主线

一个目标组可以包含听课、练习、实验、复盘等不同任务，因此组本身不设置统一产出单位。主线表达阶段目标及其时间信息；具体任务表达为达成目标而采取的行动。

每个目标组拥有永久、唯一的标识符。改名、编辑主线、调整节点时间都不能改变它；标识符不能根据名字、内容或日期重新计算。主线可以在没有任何任务实例时独立存在。

### 主线节点与配对

实例由模板印刷，主线负责配对与裁定。实例的所属目标组标识符与**计划执行开始时间**共同决定节点配对——匹配依据是执行时间，不是印刷时间，所以提前印刷不会改变执行日期。

节点关心三个过程事实：是否成功配对任务、配对任务是否全部完成、节点是否完成。默认要求至少配对一条任务且配对任务全部完成，可增加数量要求或人工确认。没有实例不算完成；空集合的「全部完成」不能当成节点已完成。

节点区间为包含起点、不包含终点，按时间排列且不重叠；有日期但没有提醒时刻的实例按当天 00:00 配对，无日期实例暂不配对。删除实例保留配对记录，未完成的被删任务不会变成完成；调整未裁定任务的所属组或执行时间会重新配对，编辑主线范围只影响之后建立的配对。

### 信号裁定与阻断

节点没有自行过期状态。完成只是过程信息，成功/失败由信号裁定：普通节点默认不发信号；有权限的节点可以按时间，或时间与自身完成情况共同触发成功/失败信号，方向可向头或向尾。成功与失败信号不检查接收节点是否完成，且裁定不可撤销。

有发信号权限的节点可分别为成功和失败信号设置不阻断、无条件阻断或基于配对/完成状态的条件阻断。拒绝时该节点不接受裁定，传播停止；普通节点不阻断。末节点的检查信号固定向头传播，不可阻断，只把已完成且尚未裁定的节点变成成功。

节点成功或失败后，所有配对实例都报废，已经完成的记录仍保留；正在进行的该实例专注会停止并记录实际已用时间。模板的印刷安排独立存在，后来进入已裁定节点的实例同样报废。信号记录可查看发出者、裁定内容、接收路径和阻断原因。

「成功」与「失败」都报废任务，但不能合并——否则无法解释免做、认可、失格或验收否定等不同结果。完整定义与实现边界见 [NODE_DESIGN.md](NODE_DESIGN.md)。

### 项目是另一个维度

项目的管辖与目标、习惯**相互独立**——不是上下级，也不是平级，而是两个正交的轴：

- 目标 / 习惯回答「**这件事该怎么执行、漏了怎么办**」；
- 项目回答「**做这件事时，该处在什么环境里**」。

项目的抽象意义在于**构造学习环境**：不同类型、不同科目的任务需要不同的环境（放行哪些应用、屏蔽哪些干扰）。所以专属应用白名单挂在项目上，而不是挂在目标或习惯上——同样是「听课」，英语课和编译原理课需要的软件并不一样。

### 愿景：天马行空的理想

愿景的前身是「**开放性任务**」——一个没有期限、可以一直做的任务。但分析下来发现：没有边界、没有进度、没有成败，所谓「开放任务」其实就是**画大饼**，硬塞进任务体系只会把执行语义搅浑（它到底算不算完成？漏了算不算失败？）。所以它被请出任务体系，变成纯标记的愿景：不再假装自己是待办，只老老实实当地图上的一个方向。

任务是具体的，目标是具体的，习惯也是具体的——它们都**脚踏实地**：有明确的时间、明确的进度、明确的成败。愿景不一样：它关心的是「以后想成为什么样的人」，不参与任何执行语义——不补进度、不失败、不计缺勤。它只是写给你自己的一段话：想考的学校、想过的生活、一张研究生工资的截图。

- 愿景可以挂在**项目**下（英语一 → 80 分）、挂在**目标**下（OpenCamp → 拿结营证书），也可以挂在**顶层**当总愿景（考上北大）。
- 「目标·习惯·愿景」页的**愿景**分页把它们汇总起来，配着各自的小作文。

## 模板、印刷与实例

创建入口默认是只做这一次的临时任务，也可选择保留为手动模板或自动模板。填写预计分钟数即可自动安排专注，不要求用户计算番茄数；短任务自动缩短单次专注，其他任务向上预留完整时段并预览含休息的总计划块。

「自动印刷」是独立选项。关闭时保留静态模板，随时手动选择起止日期，批量印刷所选日程或日期涉及的整个周期；开启时每次运行/轮询滚动补齐近期安排，默认提前 7 天，可设 0–90 天。重复模板每次印完涉及的完整周；非重复日程补齐截止预印日期的安排，包括尚未报废的逾期日程。印刷会补齐范围内的遗漏，不依赖日期首次进入窗口；同模板同日期不会重复印刷，删除实例也不会重建。程序关闭期间不执行。

模板保存标题、备注、步骤、项目、单次时长、标签和默认优先级，再选择非重复日程或每周周期。一个开始时间对应多个日期或周期单元，可在一份模板里添加多个开始时间，共用任务内容。日期、完成、统计属于已印实例，实例不保存重复规则，完成实例不会生成下一条。

普通组的重修窗口以分钟计，从计划块结束起算，仅当天有效，默认 0；目标实例由配对节点的信号裁定管理，习惯不重修。模板修改只影响未来，显式「同步到未完成实例」才更新现有形状，保留实例日期、管辖、步骤进度及专注历史。删除模板保留实例。编辑器也保留直接创建一条实例的快捷方式。

完整字段与往返规则见 [PLAN_FORMAT.md](PLAN_FORMAT.md)。
