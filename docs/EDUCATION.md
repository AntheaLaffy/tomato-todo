# 项目资料与应试教学

项目把资料、学期进度、课程和训练证据关联起来，让助手能根据实际表现调整安排。侧栏「应试教育」聚合学生和教师视图；项目页的「项目资料与应试教学」保留资料库与完整教学记录，点击「让助手备课」进入助手。普通任务继续表达自由执行的事情，正式教学记录使用独立模型。

## 项目与目录

新建项目必须指定已经存在的专用绝对目录；桌面使用系统目录选择器，浏览器预览输入本机路径。旧项目、示例和计划导入项目可以暂时没有本机授权，不能据此读写宿主资料。用户在项目页选择或重新授权后，`project-grants.json` 单独保存在助手私有目录。备份中的 directory 只是绑定元数据，不会授予权限。

每轮 Pi 会话只挂载绑定路径与本机授权一致、仍然存在且未变成符号链接的目录。文件工具、grep 和持久终端使用相同范围；授权变更要求助手空闲。不同项目的授权目录不能重叠，不允许授权整个主目录、根目录或应用私有数据目录。完整访问/作者模式仍遵循原有显式设置。

上传资料前至少授权一个项目目录；未指定 projectId 的聊天上传暂归第一个已授权项目，可专门创建「未分类」项目作为收件处。助手可通过 education.saveResource 整理资料类型；跨项目归档前先复制文件到目标授权目录，再更改资源归属与相对路径。聊天保留私有交付副本，历史/分支引用不会因项目分类改变而失效；项目目录中保存资源文件。现有聊天单文件8MB、单条20MB限制继续适用，大文件可以先自行放到项目目录再让助手登记。

资料目录整体搬家后，在项目页显式选择新目录重新授权；相对路径与资源 ID 保留，随后检查失效登记。删除尚无学期记录的项目只删除应用索引，不删除外部文件；已有教学历史的项目须保留，停用应试模式停止未来教学事件。

## 资料查找、预览与清理

项目资料库按名称、相对路径、来源、版本与知识点搜索，可按类型及检查后的文件状态筛选，每页40条。作业题目来源、课程、本周指定资料、答卷与订正附件可直接打开资源，不必回资料库按名称翻找。登记仅表示资源可关联，不代表助手已经读取内容；目前没有资料全文/OCR索引或独立阅读状态追踪。搜索文本和资源引用按当前数据建立索引并复用，资料库展开状态跨重绘保留；仅用户发起检查时读取文件状态，不在轮询中扫描资料目录。

图片、PDF和文本支持应用内预览，预览路径上限20 MiB；文本显示前20万字符。原件下载没有此大小限制：桌面使用系统保存对话框并从文件流复制到临时文件后替换目标，浏览器使用文件响应并支持Range，不把整个大文件经Base64送进前端。桌面可用系统应用打开原件。聊天上传的8MB限制仍独立适用，大教材可先放入授权目录后登记。

「检查失效登记」只读文件状态，不遍历内容；区分文件缺失和目录未授权、目录失联、权限错误等暂不可用状态，并列出教学引用。「修复路径」验证新文件后保留原ID及所有引用；整体搬家用重新授权。「清理缺失且无引用的登记」先展示确认数量，再重新核查文件仍缺失；单条也可移除没有引用的登记。清理只移除索引，不删除磁盘文件；项目配置、历史学期计划、课程、试题、答卷和订正引用的登记须保留，不能清理。导入同样不允许删除已有教学证据。

## 应试教育面板

学生端聚合今日/逾期任务、考试中与待交/订正/复核事项、未来一周课程与测评、最近实际学情和下一步建议入口。教师端对照当前学期教学周的里程碑、指定资料、计划/已排课时、实际参与、课程进度、发布/提交/批改及学情依据；教学周从学期起始日起算，末周按学期结束日裁剪。

两个视图读取同一份权威快照，不是独立账号或服务端权限角色。提交、批改与订正按当前快照建立索引，复用查询并随旧快照释放。待办状态从全部提交和批改推导，同秒多版本以最后保存版本为准；项目页展示完整课程和测评。助手入口预填备课/复盘请求，用户发送后按既有交互权限执行。

## 启用与备课

应试项目必须有愿景、具体考试目标、考纲、真题、模拟题。资源带来源、版本与知识点，考纲需要明确年份和适用范围。先导入资料，再保存应试配置；缺少前置条件会被核心拒绝。

助手通过 `education` 工具维护正式记录，字段见随包技能 `exam-teaching/contract.md`。学期计划记录学情起点、证据、排期理由与每周知识点、资源及课时；修改递增版本并保留旧版本。已有课程也须与考纲及可查证经验核对，资源不足时联网补充；真实目标院校和考试规则由助手联网核实，不在安装包放入个人备考数据。

课程必须绑定本项目学期，固定45分钟；跨项目合计上午最多4节、下午最多4节，不与正式占用、其他课程或考试冲突。完整学习日按上午4节、下午2–4节安排，零散增排时不强制已经凑齐每天最低节数。课程开始后用户确认参与并记录实际进度；到点状态变成已下课或缺课，不产生番茄或掌握记录。需要AI的已参与课程下课后生成作业事件。

## 学情进度

项目页的「最新学情」按主题展示实际学到的位置、依据、状态、下一步、来源和确认状态；支持用户本人登记、确认助手整理的记录。每条进度记录保留历史，不以原地覆盖实现更正。`get_context`为助手提供带`asOf`的短摘要，`get_study_progress`按项目分页提供进度记录、任务快照、七日实际计时、作业/考试状态、提交、正式成绩、订正与复测关系。摘要由当前证据动态计算，不另存可失真的副本；待复核批改不发布正式分数。

任务勾选与实际番茄、知识掌握相互独立。启用应试模式项目的学习任务完成时，核心一次性保存任务内容快照并生成`taskHomework`教学事件；任务随后被移动或删除不影响来源追溯。助手按快照和最新学情决定是否能出题，作业以`taskId`关联原任务、`lessonId=null`。作业只能覆盖有依据的已学范围；不明部分先核实，不机械补齐通用分钟数。

## 作业、考试与复盘

正式作业、考试、学期计划、课程和批改不能由普通手动 Action 创建，只能交给助手。备份恢复用于恢复已有正式记录；发布过的题目、答案和评分标准不能用导入/补丁覆写。普通任务不被自动解释成正式作业。

每份发布包包含题目、来源、知识点、估时、标准答案、可接受替代解法、分步评分点与独立复核记录。基础练习覆盖已学知识，拓展题明确标记；全真模拟允许覆盖完整考纲。规则校验不能证明AI答案正确，实际复解与复核由助手执行，用户可要求复核。

180分钟是全科作业供给的通用聚合基线，不是每科配额或必须补足的最低量；用户明确要求的时间表、固定课程和当日负荷优先，课程量与作业量分开核算，负荷较重时减少作业而不追补差额。19:00–22:00是默认晚间作业窗口，实际作息以用户设置为准；到收工时间提交已完成部分，未完成内容如实保留。复盘按用户作息与固定课程安排，不使用与现实冲突的统一默认钟点。

周五至周末为每个启用项目的当前学期生成周考准备事件；助手分配周末两天的考试窗口，避免跨项目各排一整天。阶段测试覆盖已学，全真模拟使用目标考试完整规则。试卷和答题卡导出为可打印的独立HTML，不含标准答案；逐题填写本机显示的HH:MM完成时刻。确认打印后才能在窗口开始考试。开始过的考试到点自动停笔，界面提示上传答题卡，考试答卷必须含项目资源附件；晚交仍保存真实提交时间，不伪装准时。照片与自报时刻不能证明线下考场行为。

提交不可覆盖，重交创建新版本。批改逐评分点记录得分和答卷证据，禁止超分、重复评分、增加临时评分点或漏掉正式评分点。识别不清设置needsReview，不作确定评分；合理新解法请求复核。复核使用新批改ID保留旧记录。错因分析记录依据、纠正动作、下次检查信号与复测日期，未证实的原因保留待确认。订正按原批改和题目提交，独立教学事件检查后保存接受/继续订正及反馈；即使订正通过，仍须通过关联原批改的独立复测试卷验证掌握。

## 持久化与执行

备份v4新增可选 `education` 对象（旧备份缺省为空）：projects/resources/semesters/semesterHistory/lessons/assessments/submissions/grades/reviews/events/completedTasks/progress/corrections。计划v6继续只交换普通计划，不承载教学历史，不移除本地教学记录。目录资源与本机授权不打包进JSON备份，需单独备份外部目录；换机恢复后重新选择目录授权。

核心tick负责到点状态和homework/grade/review/weeklyExam事件。事件以固定来源ID去重，状态pending/running/done，和普通数据一起原子持久化；每日复盘等错过的状态在重新运行后补齐。已连接且空闲时，宿主领取待处理事件，沿用现有 scheduled Pi 会话语义，执行时可使用正式教学工具，不另加模型调度层、时限或循环重试。助手保存实际产物后finishEvent；用户停止、供应商错误或关机留下未完成事件，由助手在用户要求继续时调用retryEvent恢复处理。停用应试模式不再领取该项目事件，已开始请求需用户主动停止。

应用关闭时不运行模型，模型不可用时等待；试卷截止状态在下次tick恢复，无法关机时响铃。当前无离线OCR引擎，PDF/照片的识别取决于沙箱工具和所连接模型的视觉能力。

验证：`cargo test -p tomato-core -p tomato-agent --lib`、`node --test tests/education.mjs tests/agent.mjs tests/agent-workspace.mjs`；只使用临时目录、本机mock模型与隔离浏览器，不动真实学习资料、不花模型额度、不启用当前桌面保护。
