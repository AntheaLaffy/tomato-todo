# 项目资料与应试教学

项目把资料、学期进度、课程和训练证据关联起来，让助手能根据实际表现调整安排。入口是项目页的「项目资料与应试教学」，随后点击「让助手备课」。普通任务继续表达自由执行的事情，正式教学记录使用独立模型。

## 项目与目录

新建项目必须指定已经存在的专用绝对目录；桌面使用系统目录选择器，浏览器预览输入本机路径。旧项目、示例和计划导入项目可以暂时没有本机授权，不能据此读写宿主资料。用户在项目页选择或重新授权后，`project-grants.json` 单独保存在助手私有目录。备份中的 directory 只是绑定元数据，不会授予权限。

每轮 Pi 会话只挂载绑定路径与本机授权一致、仍然存在且未变成符号链接的目录。文件工具、grep 和持久终端使用相同范围；授权变更要求助手空闲。不同项目的授权目录不能重叠，不允许授权整个主目录、根目录或应用私有数据目录。完整访问/作者模式仍遵循原有显式设置。

上传资料前至少授权一个项目目录；未指定 projectId 的聊天上传暂归第一个已授权项目，可专门创建「未分类」项目作为收件处。助手可通过 education.saveResource 整理资料类型；跨项目归档前先复制文件到目标授权目录，再更改资源归属与相对路径。聊天保留私有交付副本，历史/分支引用不会因项目分类改变而失效；项目目录中保存资源文件。现有聊天单文件8MB、单条20MB限制继续适用，大文件可以先自行放到项目目录再让助手登记。

已有资料时不支持直接把绑定指向另一目录，防止静默丢失引用。删除尚无学期记录的项目只删除应用索引，不删除外部文件；已有教学历史的项目须保留，停用应试模式停止未来教学事件。

## 启用与备课

应试项目必须有愿景、具体考试目标、考纲、真题、模拟题。资源带来源、版本与知识点，考纲需要明确年份和适用范围。先导入资料，再保存应试配置；缺少前置条件会被核心拒绝。

助手通过 `education` 工具维护正式记录，字段见随包技能 `exam-teaching/contract.md`。学期计划记录学情起点、证据、排期理由与每周知识点、资源及课时；修改递增版本并保留旧版本。已有课程也须与考纲及可查证经验核对，资源不足时联网补充；真实目标院校和考试规则由助手联网核实，不在安装包放入个人备考数据。

课程必须绑定本项目学期，固定45分钟；跨项目合计上午最多4节、下午最多4节，不与正式占用、其他课程或考试冲突。完整学习日按上午4节、下午2–4节安排，零散增排时不强制已经凑齐每天最低节数。课程开始后用户确认参与并记录实际进度；到点状态变成已下课或缺课，不产生番茄或掌握记录。需要AI的已参与课程下课后生成作业事件。

## 作业、考试与复盘

正式作业、考试、学期计划、课程和批改不能由普通手动 Action 创建，只能交给助手。备份恢复用于恢复已有正式记录；发布过的题目、答案和评分标准不能用导入/补丁覆写。普通任务不被自动解释成正式作业。

每份发布包包含题目、来源、知识点、估时、标准答案、可接受替代解法、分步评分点与独立复核记录。基础练习覆盖已学知识，拓展题明确标记；全真模拟允许覆盖完整考纲。规则校验不能证明AI答案正确，实际复解与复核由助手执行，用户可要求复核。

全科作业供给估时至少180分钟是助手备课规则，项目页展示当天合计与目标；它不是对实际学习时长的测量，也不是每个项目各布置180分钟。19:00–22:00是默认晚间作业时段，22:00收取已做部分，未完成可以如实提交。次日08:30复盘前一晚；固有课程或其他现实占用冲突时，助手调整安排并说明。

周五至周末为每个启用项目的当前学期生成周考准备事件；助手分配周末两天的考试窗口，避免跨项目各排一整天。阶段测试覆盖已学，全真模拟使用目标考试完整规则。试卷和答题卡导出为可打印的独立HTML，不含标准答案；逐题填写本机显示的HH:MM完成时刻。确认打印后才能在窗口开始考试。开始过的考试到点自动停笔，界面提示上传答题卡，考试答卷必须含项目资源附件；晚交仍保存真实提交时间，不伪装准时。照片与自报时刻不能证明线下考场行为。

提交不可覆盖，重交创建新版本。批改逐评分点记录得分和答卷证据，禁止超分、重复评分、增加临时评分点或漏掉正式评分点。识别不清设置needsReview，不作确定评分；合理新解法请求复核。复核使用新批改ID保留旧记录。错因分析记录依据、纠正动作、下次检查信号与复测日期，未证实的原因保留待确认。

## 持久化与执行

备份v4新增可选 `education` 对象（旧备份缺省为空）：projects/resources/semesters/semesterHistory/lessons/assessments/submissions/grades/reviews/events。计划v6继续只交换普通计划，不承载教学历史，不移除本地教学记录。目录资源与本机授权不打包进JSON备份，需单独备份外部目录；换机恢复后重新选择目录授权。

核心tick负责到点状态和homework/grade/review/weeklyExam事件。事件以固定来源ID去重，状态pending/running/done，和普通数据一起原子持久化；每日复盘等错过的状态在重新运行后补齐。已连接且空闲时，宿主领取待处理事件，沿用现有 scheduled Pi 会话语义，执行时可使用正式教学工具，不另加模型调度层、时限或循环重试。助手保存实际产物后finishEvent；用户停止、供应商错误或关机留下未完成事件，用户在项目页明确重试。停用应试模式不再领取该项目事件，已开始请求需用户主动停止。

应用关闭时不运行模型，模型不可用时等待；试卷截止状态在下次tick恢复，无法关机时响铃。当前无离线OCR引擎，PDF/照片的识别取决于沙箱工具和所连接模型的视觉能力。

验证：`cargo test -p tomato-core -p tomato-agent --lib`、`node --test tests/education.mjs tests/agent.mjs tests/agent-workspace.mjs`；只使用临时目录、本机mock模型与隔离浏览器，不动真实学习资料、不花模型额度、不启用当前桌面保护。
